# PRODIGY_WD_03XO Arena – Tic Tac Toe Web Game

XO Arena is a modern and interactive Tic Tac Toe web application developed using HTML, CSS, and JavaScript. The project presents the classic two-player game with an attractive user interface, smooth animations, and a visually appealing dark theme enhanced with neon purple and blue colors. The main objective of this project is to provide an enjoyable gaming experience while demonstrating essential web development concepts.

The application allows two players to compete against each other on a three-by-three game board. Player One uses the symbol X, while Player Two uses the symbol O. Players take turns selecting empty squares, and the first player to align three identical symbols horizontally, vertically, or diagonally wins the round. If all nine squares are filled without a winning combination, the game declares a draw.

One of the major features of XO Arena is its automatic winner detection system, implemented using JavaScript. The application checks all possible winning combinations after every move and highlights the winning cells when a player wins. It also prevents players from selecting occupied squares or continuing to play after the round has ended.

The game includes a live scoreboard that tracks the victories of both players and the number of drawn matches. The Restart Round button allows players to begin another round while preserving their scores, whereas the New Game button resets the entire match and clears the scoreboard. Optional sound effects provide additional feedback during gameplay.

The user interface is designed with CSS gradients, glowing effects, responsive layouts, rounded cards, and smooth transitions. Its responsive design ensures compatibility with desktop computers, tablets, and mobile devices. Accessibility features, including descriptive button labels and keyboard focus indicators, make the application easier to use.

The project uses HTML5 to structure the game, CSS3 to style the interface and animations, and JavaScript to manage game logic, player turns, score tracking, and interactive controls. It does not require a database, server, or additional JavaScript libraries.

In conclusion, XO Arena is a simple yet engaging web development project that combines functionality, creativity, and responsive design. It helps beginners understand programming logic, event handling, conditional statements, arrays, and DOM manipulation while creating a practical and entertaining browser-based game.
